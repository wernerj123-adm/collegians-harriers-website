A prediction run where the closest estimate matters more than the fastest watch.

GoalFinish closest to 18:00

CharacterSocial, not an official race
HOW IT WORKS

Estimate first.
Run second.

Participants select the 5 km or 10 km option, estimate their finishing time, and set out without a watch, phone or timing device. There is no common start time: the challenge is to return as close as possible to 18:00.

The historical format uses an out-and-back route with a refreshment turnaround near Hesketh Drive. It is a social run or walk without road closures or formal race marshalling.
