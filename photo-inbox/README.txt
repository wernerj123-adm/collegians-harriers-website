COLLEGIANS HARRIERS PHOTO INBOX

1. Copy approved JPG, JPEG or PNG photographs into this folder.
2. Double-click "Publish Photos.cmd" in the main website folder.
3. Follow the prompts for the date, album/event name, title, activity, alternative text and caption.
   Use the same album name for every photograph from one day or event.
4. Review the details before choosing whether to publish to the develop preview.

Only publish club-approved photographs. Confirm permission for identifiable
people, especially children, and do not include private personal information.
